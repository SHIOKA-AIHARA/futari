# しおか＆ゆうとの予定帳（ホーム画面の名前は Calendário）

ふたりの空き（朝・昼・夜・泊まり）を入れて、週1で会う日を決めるiPhone向けアプリ（ホーム画面に追加して使うWebアプリ）。

## しくみ

- `public/` … アプリの画面（`index.html` / `app.js` / `app.css`）、通知を受け取る `sw.js`、アイコン
- `src/worker.js` … Cloudflare Workers で動くサーバー
  - ふたりのデータは Durable Object「Pair」1つにまとめて保存
  - 開いている画面どうしは WebSocket でリアルタイムに同期
  - 通知は Web Push で送る（鍵は初回に自動で作成）
- `wrangler.jsonc` … Cloudflare の設定。毎日 20:00（日本時間）にシフト〆切と「来週の会う日」をチェック

## 公開のしかた

Cloudflare の Workers で、このリポジトリを読み込んでデプロイする（`npx wrangler deploy`）。
Worker の名前は `futari` にする。

## 専用リンク

`https://<WorkerのURL>/?k=<合言葉>` を開くと、合言葉に応じて「しおか」か「ゆうと」として入れる。
リポジトリには合言葉そのものは置かず、SHA-256 のハッシュだけを `wrangler.jsonc` の `KEY_HASH_SHIOKA` / `KEY_HASH_YUTO` に置いている。
合言葉を変えたいときは、新しい合言葉のハッシュに書きかえてデプロイする。

## 通知が届くタイミング

- 相手が空きを入れたとき（入力が10分止まったらまとめて1回）
- 相手の都合が変わって、決めた予定のコマが空かなくなったとき
- 相手がシールを貼った・なおした・決定にした・はがした・もどしたとき
- シフト提出の5日前（ふたり）と前日（しおか）
- 日曜の夜、来週の会う日がまだ決まっていないとき（ふたり）
